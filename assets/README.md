## 换图 / 加图

直接覆盖同名文件即可。要改张数，编辑 `js/data.js`：

```js
images: IMG(3, 2)   // 第 3 条，2 张 → p03-1、p03-2
```

- `IMG(3, 5)` → 5 张
- `[]` → 纯文字
- `["assets/别的名字.jpg"]` → 用任意文件名

## 压缩

单张平均 180 KB，全站图片约 7 MB。以后换图建议保持同样规格。
